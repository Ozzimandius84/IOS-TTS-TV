# IOS-TTS-TV — Frank on a phone

The phone app. One repo, and it is not TTSTV: the reader is imported here as a
built artefact and this repo carries the app that wraps it.

```
shell/                the app shell, byte-for-byte what TTSTV's
                      reader/tools/publish_shell.py writes, plus one index.html.
                      NEVER EDITED BY HAND. Regenerated by one command.
shell.manifest.json   what arrived, and its sha256s. Checked before every build.
src-tauri/            the Tauri 2 project: frank:// serving shell/ off the app's
                      data dir, gen/apple for Xcode, gen/android after init.
tools/                import_shell.py (the one command) · prebuild.py (the check
                      tauri runs) · android_permissions.py · shell_manifest.py
tests/                python; no cargo, no phone, no network
PHONE.md              how to import, how to build for each phone, what's owed
_to_delete/           this shell cannot delete files; Osca empties it
```

**The route, and nothing is hand-copied along it:**
`design/reader/` → (TTSTV job 15) → `reader/` → `reader/tools/publish_shell.py`
→ `shell/` here. The app never loads from `design/`.

**The list of what the shell is lives in TTSTV**, in `reader/sw.js`'s
`SHELL_FILES`, and this repo restates no part of it. What it keeps is a record
of what arrived — see `tools/shell_manifest.py` for why a record is not a list.

Everything else: **`PHONE.md`**.
